# Prompt comum para os candidatos

Implemente o protótipo jogável **Rabisco Tênis** neste repositório. Leia `PRD.md`, `references/README.md`, as três imagens ali listadas e `benchmark/tasks/01.md` até `benchmark/tasks/08.md`. Entregue uma partida completa no navegador, conforme os critérios de aceite dessas tarefas.

Trabalhe apenas nesta cópia do projeto. Você pode criar código, recursos e testes necessários. Preserve o PRD, as referências visuais e os arquivos de `benchmark/` e `.github/ISSUE_TEMPLATE/`. Atualize o README com comandos para instalar, iniciar, gerar o build e jogar, sem identificar o modelo candidato no código ou na documentação. Ao terminar, execute as verificações disponíveis e relate o resultado, o commit final e limitações conhecidas.

Condições de tempo, ferramentas e acesso externo são informadas pelo avaliador de forma idêntica a todos os candidatos da rodada. Não consulte implementações de outros candidatos.
